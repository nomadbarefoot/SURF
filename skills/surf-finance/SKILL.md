# SURF Finance

Choose only the dataset needed for the question.

- Use `finance_analyst_consensus` for price targets and EPS estimates.
- Use `finance_insider_transactions` for insider activity and promoter pledges.
- Use `finance_corporate_actions` for dividends, splits, buybacks, and related events.
- Use `finance_macro` for sovereign yields, credit spreads, and FX data.
- Use `finance_equity_risk_premium` for country risk comparisons.
- Use `finance_us_snapshot` for a basic US equity snapshot.

State the symbol, market, country, and retrieval context used. Treat results as research data, flag missing or stale fields, and use `surf-web` when narrative sources or current disclosures are also required.
